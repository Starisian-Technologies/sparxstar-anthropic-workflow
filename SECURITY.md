# Security Policy

## Supported scope
Security reports should cover:
- `.github/workflows/` reusable workflow logic
- Prompt assembly and API invocation flow
- GitHub token permissions and comment-writing behavior
- Repository governance templates and instructions

## Reporting a vulnerability
Do **not** open public issues for vulnerabilities.

Report privately via:
- GitHub Security Advisories (preferred)
- Email: security@starisian.com

Include:
- Affected file(s)
- Reproduction steps
- Impact assessment
- Suggested mitigation (if known)

## Response targets
- Initial acknowledgement: within 3 business days
- Triage decision: within 7 business days
- Remediation timeline: based on severity and deployment risk

## Disclosure
Coordinated disclosure is required. Public disclosure before remediation approval is prohibited.
